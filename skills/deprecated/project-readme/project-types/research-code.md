# Research Code

## Primary reader

Researcher reproducing or extending results.

## First successful action

Reproduce a table, figure, metric, or experiment.

## First screen

Show paper/project, result to reproduce, environment setup, and one command.

## Required sections

Environment, data/checkpoints, reproduction commands, results, citation, license.

## Conditional sections

Training, evaluation, notebooks, hardware, expected runtime, troubleshooting.

## Source-of-truth files

CITATION, paper links, notebooks, train/eval scripts, configs, results, checkpoints.

## Do not invent

Metrics, hardware, runtime, dataset access, checkpoint URLs, paper claims.

python scripts/eval.py --config configs/default.yaml
