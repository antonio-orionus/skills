# Docs Site

## Primary reader

Reader or maintainer of a documentation site.

## First successful action

Read the docs or run/build the docs site locally.

## First screen

Show what the docs cover, where to read them, and the local docs command.

## Required sections

Read docs, run locally, content structure, authoring, build/deploy, license.

## Conditional sections

Theme, search, versioning, generated API docs, contribution workflow.

## Source-of-truth files

Docs generator config, `docs/`, content files, package scripts, deployment config.

## Do not invent

Hosted URLs, doc coverage, site metrics, deploy providers, version policies.

Example:

mkdocs serve
