# Section Order

Use the project-type module first. This matrix gives default order; omit unsupported sections.

## Universal First Screen

1. `# Name`
2. Real badges, if useful
3. One or two sentence value proposition
4. Fastest real action

## Matrix

- `lib-or-sdk`: install, minimal import, usage examples, API reference, configuration, examples, development, license.
- `cli`: quick start, install, command reference, examples, configuration, development, troubleshooting, license.
- `webapp`: run locally, configuration, features or screenshots when real, deployment, development, testing, troubleshooting, license.
- `api-service`: run locally, make one request, API docs or endpoint summary, configuration, deployment, development, testing, troubleshooting, license.
- `mcp-server`: client config, available tools, transport, install/run, examples, development, troubleshooting, license.
- `agent-skill`: install path, skill index when collection, trigger conditions or prompts, workflow, bundled resources, examples, validation, license.
- `monorepo`: workspace map, package index, root setup, per-package commands, development, testing, release, license.
- `docs-site`: read docs, run docs locally, content structure, authoring, build/deploy, license.
- `github-action`: workflow snippet, inputs, outputs, examples, permissions, versioning, development, license.
- `extension-plugin`: install into host, activate feature, configuration, commands/features, development, packaging, license.
- `container-image`: image, run command, configuration, volumes/ports, compose/Kubernetes examples if real, build, license.
- `terraform-module`: module block, inputs, outputs, examples, requirements, testing, license.
- `helm-chart`: helm install, values, templates/resources, examples, upgrade/uninstall, chart development, license.
- `model-card`: intended use, load/run, model details, evaluation, limitations, license/citation.
- `dataset-card`: load sample, schema, splits, license, provenance, intended use, limitations, citation.
- `research-code`: reproduce result, environment, data/checkpoints, train/eval commands, results, citation, license.
- `template-starter`: create new project, customize placeholders, included stack, generated structure, update path, license.
- `example-demo`: run demo, what it demonstrates, source tour, variations, cleanup, license.
- `spec-protocol`: status, audience, conformance, schemas, examples, versioning, license.
- `desktop-mobile-app`: run target platform, requirements, configuration, build/package, development, testing, license.
