# Spec Protocol

## Primary reader

Implementer or validator of a protocol or specification.

## First successful action

Understand the spec and run or inspect conformance checks.

## First screen

Show spec status, audience, main document, and conformance path.

## Required sections

Status, scope, documents/schemas, examples, conformance, versioning, license.

## Conditional sections

Reference implementations, compatibility, governance, changelog, security.

## Source-of-truth files

Spec/RFC files, schemas, OpenAPI files, conformance tests, examples.

## Do not invent

Standards status, compatibility, governance, implementations, security guarantees.
