# Usage Examples

Examples must match real APIs, commands, tools, files, routes, charts, modules, models, or datasets.

- Start with the smallest example.
- Add a realistic second example only when source/examples/tests support it.
- Prefer examples from `examples/`, tests, docs, or typed exports.
- Include imports and commands that can be copied.

Do not invent output unless tests, snapshots, docs, or source prove it.
