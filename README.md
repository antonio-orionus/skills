# skills

Claude Code skills for AI-assisted development workflows.

## Install

Add this plugin to your Claude Code project:

```bash
claude plugin add antonio-orionus/skills
```

Or install globally:

```bash
claude plugin add --global antonio-orionus/skills
```

## Skills

### Documentation

| Skill | Description |
|-------|-------------|
| [`npm-github-readme`](skills/documentation/npm-github-readme/SKILL.md) | Create, update, or validate README files for npm packages and GitHub repositories |
