# Web App

## Primary reader

Developer or operator running a user-facing application.

## First successful action

Run the app locally and open it in a browser.

## First screen

Show the app name, audience, local run command, and URL if the repo proves it.

## Required sections

Local setup, configuration, development, test/build, deployment when supported, license.

## Conditional sections

Screenshots, live demo, auth setup, environment variables, database setup, troubleshooting.

## Source-of-truth files

Framework config, package scripts, `app/`, `pages/`, `src/routes/`, `public/`, env examples.

## Do not invent

Live URLs, screenshots, features, auth providers, deploy targets, database requirements.
