# License

Use when a license file, SPDX field, package metadata, model card, dataset card, or citation source proves the licensing terms.

## Content

- Link to the license file when present.
- Include the SPDX id or common license name when detected.
- Include author or copyright-holder credentials when `license.copyright_holder`, `license.copyright_notice`, or package author metadata proves them.
- If the repo proves both license and holder, a compact section is enough, for example: `MIT (c) 2026 Antonio Orionus`.

## Do not invent

- Copyright holders, author names, years, organizations, or ownership from repository names alone.
- License terms when no license source exists.
- Legal interpretation beyond the detected license and source-backed notice.
