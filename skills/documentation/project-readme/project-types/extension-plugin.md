# Extension Plugin

## Primary reader

User installing an extension or plugin into a host platform.

## First successful action

Install into the host and activate one feature.

## First screen

Show the host platform, what the extension adds, install path, and first action.

## Required sections

Installation, activation/use, commands/features, configuration, development/package, license.

## Conditional sections

Marketplace link, host compatibility, screenshots, permissions, troubleshooting.

## Source-of-truth files

Host manifest, `package.json` `engines` and `contributes`, `manifest.json`, `plugin.xml`.

## Do not invent

Marketplace URLs, host versions, permissions, commands, screenshots, feature lists.
